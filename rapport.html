3. Conception

3.1 Architecture

L'application suit une architecture client-serveur MVC basée sur Django :

  • Frontend : HTML5, CSS3, Bootstrap 5, JavaScript
  • Backend : Python 3, Django 5
  • Base de données : PostgreSQL

Le projet est découpé en 4 applications Django :

  • accounts — Gestion des utilisateurs, authentification, profil
  • matching — Algorithme de correspondance mentor/mentoré
  • messagerie — Conversations et messages
  • offres — Publication et recherche d'offres/demandes de mentorat

3.2 Schéma de la Base de Données

9 tables PostgreSQL :

TableDescriptionClés importantes
utilisateursComptes utilisateursPK: id, UNIQUE: email, telephone
disponibilitesCréneaux horairesFK: utilisateur_id
competencesRéférentiel des matièresPK: id, UNIQUE: nom
points_fortsCompétences maîtriséesFK: competences_id, utilisateurs_id
points_faiblesCompétences à améliorerFK: competences_id, utilisateurs_id
offres_mentoratOffres et demandes publiéesFK: utilisateurs_id, competences_id
matchingCorrespondances calculéesFK: mentor_id, mentore_id
conversationsFils de discussionFK: matching_id
messagesMessages individuelsFK: conversations_id, expediteur_id

3.3 Algorithme de Matching

Le score de compatibilité est calculé selon 3 critères pondérés :

  • Compétences (50%) : intersection entre les points faibles du mentoré et les points forts du mentor
  • Disponibilités (30%) : jours communs dans les créneaux horaires
  • Filière (20%) : bonus si même filière

4. Instructions de Déploiement

Prérequis

  • Python 3.10+
  • PostgreSQL 14+
  • pip

Étapes

# 1. Cloner le dépôt
git clone https://github.com/Faridadss7/PIL1_2526_02.git
cd PIL1_2526_02

# 2. Créer un environnement virtuel
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. Installer les dépendances
pip install -r requirements.txt

# 4. Configurer les variables d'environnement
export DJANGO_SECRET_KEY="votre-cle-secrete"
export DB_NAME="mentorlink"
export DB_USER="postgres"
export DB_PASSWORD="votre-mot-de-passe"

# 5. Créer la base de données PostgreSQL
psql -U postgres -c "CREATE DATABASE mentorlink;"

# 6. Initialiser la base de données (schema.sql)
psql -U postgres -d mentorlink -f database/schema.sql

# 7. Appliquer les migrations Django
python manage.py migrate

# 8. Lancer le serveur
python manage.py runserver

5. Manuel d'Utilisation

Inscription

  1. Accédez à la page d'accueil : http://localhost:8000/
  2. Cliquez sur "Commencer" ou "Créer un compte"
  3. Remplissez le formulaire (nom, prénom, email, téléphone, filière, niveau, mot de passe)
  4. Sélectionnez vos points forts et points faibles selon votre niveau

Connexion

  1. Accédez à http://localhost:8000/accounts/connexion/
  2. Entrez votre email et mot de passe

Trouver un mentor

  1. Depuis le menu : Correspondances → Lancer le matching
  2. L'algorithme propose les mentors compatibles avec un score de compatibilité
  3. Cliquez sur "Discuter" pour ouvrir une conversation

Publier une offre

  1. Depuis le menu : Offres & Demandes
  2. Choisissez "Créer une offre" ou "Envoyer une demande"
  3. Sélectionnez la matière, le format et ajoutez une description
