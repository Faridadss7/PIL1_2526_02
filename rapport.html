2. Architecture Technique

Frontend

HTML5, CSS3, Bootstrap 5, JavaScript

Backend

Python 3.12, Django 6.0.5

Base de données

PostgreSQL 18

Structure des applications Django
  • accounts - Authentification, profil utilisateur
  • matching - Algorithme de correspondance
  • messagerie - Conversations et messages
  • offres - Offres et demandes de mentorat
Schéma de la base de données

9 Tables PostgreSQL :

  • utilisateurs, disponibilites
  • competences, points_forts, points_faibles
  • offres_mentorat, matching
  • conversations, messages
Algorithme de Matching

Le score de compatibilité est calculé selon 3 critères pondérés :

Compétences (50%)
Disponibilités (30%)
Filière (20%)
  • Compétences (50%) : Intersection entre points faibles du mentoré et points forts du mentor
  • Disponibilités (30%) : Jours et créneaux horaires communs
  • Filière (20%) : Bonus si même filière d'études

3. Guide de Déploiement

Note : Ce guide est conçu pour être accessible à tous, informaticiens ou non. Suivez les étapes dans l'ordre.
Prérequis
1 Python 3.12.7 est la version la plus stable avec Django

Téléchargez sur python.org

2 PostgreSQL 18

Téléchargez sur postgresql.org

3 Git

Pour cloner le dépôt

4 Éditeur de code

VS Code recommandé

Étapes d'installation
Étape 1 : Cloner le projet
git clone https://github.com/Faridadss7/PIL1_2526_02.git cd PIL1_2526_02
Étape 2 : Créer un environnement virtuel

Windows :

python -m venv venv venv\Scripts\activate

Mac/Linux :

python3 -m venv venv source venv/bin/activate
Étape 3 : Installer les dépendances
pip install -r requirements.txt
Étape 4 : Configurer PostgreSQL
# Ouvrir pgAdmin ou psql CREATE DATABASE mentorlink; CREATE USER mentorlink_user WITH PASSWORD 'votre_mot_de_passe'; GRANT ALL PRIVILEGES ON DATABASE mentorlink TO mentorlink_user;
Étape 5 : Initialiser le schéma de base de données
psql -U postgres -d mentorlink -f database/schema.sql
Étape 6 : Configurer les variables d'environnement

Créer un fichier .env à la racine du projet : ou utiliser le fichier .env contenue dans le depot github que vous allez modifier juste le mot de passe en y insérant celui de postgres

DEBUG=True DJANGO_SECRET_KEY=votre_cle_secrete_ici DB_NAME=mentorlink DB_USER=postgres DB_PASSWORD=votre_mot_de_passe <-----------Ici vous inserez votre mot de passe postgresql DB_HOST=localhost DB_PORT=5432 ALLOWED_HOSTS=localhost,127.0.0.1 EMAIL_HOST_USER=webtoonsarladss@gmail.com <---------- Ici c'est le gmail qui envoie votre lien de connexion a l'application ou de réinitialisation du mot de passe(le lien envoyé marche uniquement sur votre pc en local .Merci) EMAIL_HOST_PASSWORD=khvx jlio xgig sapg
Étape 7 : Lancer le serveur de développement

py manage.py migrate

py manage.py setup_metier

python manage.py runserver

Félicitations ! L'application est maintenant accessible à http://127.0.0.1:8000

4. Manuel d'Utilisation

Inscription
  1. Accédez à la page d'accueil : http://localhost:8000/
  2. Cliquez sur "Commencer" ou "Créer un compte"
  3. Remplissez le formulaire avec vos informations personnelles (nom, prénom, email, téléphone, filière, niveau)
  4. Choisissez un mot de passe sécurisé
  5. Sélectionnez vos points forts (matières que vous maîtrisez)
  6. Sélectionnez vos points faibles (matières où vous avez besoin d'aide)
  7. Cliquez sur "S'inscrire"
  8. Vérifiez votre boîte mail et cliquez sur le lien de confirmation (vérifiez le dossier Spam si nécessaire)
Connexion
  1. Accédez à la page de connexion : http://localhost:8000/accounts/connexion/
  2. Entrez votre adresse email et votre mot de passe
  3. Cliquez sur "Se connecter"
  4. Vous serez redirigé vers votre tableau de bord
Gestion du Profil
  1. Depuis le menu, cliquez sur "Profil"
  2. Vous pouvez modifier vos informations personnelles
  3. Mettez à jour vos points forts et points faibles
  4. Ajoutez vos disponibilités (jour et créneaux horaires)
  5. Changez votre photo de profil
  6. Cliquez sur "Enregistrer" pour sauvegarder les modifications
Offres & Demandes
Publier une offre (si vous êtes mentor)
  1. Allez dans "Offres & Demandes"
  2. Sélectionnez "Offre" dans le formulaire
  3. Cochez les compétences que vous pouvez enseigner (multi-sélection possible)
  4. Choisissez le format (présentiel, en ligne, hybride)
  5. Ajoutez vos disponibilités (jour, heure de début, heure de fin)
  6. Ajoutez une description optionnelle
  7. Cliquez sur "Publier"
Publier une demande (si vous cherchez un mentor)
  1. Allez dans "Offres & Demandes"
  2. Sélectionnez "Demande" dans le formulaire
  3. Cochez les compétences pour lesquelles vous avez besoin d'aide
  4. Choisissez le format préféré
  5. Ajoutez vos disponibilités
  6. Ajoutez une description de vos besoins
  7. Cliquez sur "Publier"
Recherche d'Offres
  1. Depuis "Offres & Demandes", utilisez les filtres de recherche
  2. Entrez un mot-clé pour chercher par matière
  3. Filtrez par disponibilité (jour)
  4. Les résultats s'affichent en temps réel
  5. Pour répondre à une offre, cliquez sur "Répondre"
  6. Une demande de matching sera envoyée au mentor
Matching Automatique
  1. Allez dans "Correspondances" → "Lancer le matching"
  2. L'algorithme analyse votre profil et calcule les scores de compatibilité
  3. Les mentors compatibles s'affichent avec leur score
  4. Pour chaque mentor, vous pouvez voir :
    • Ses points forts (compétences maîtrisées)
    • Ses disponibilités
    • Les disponibilités communes
    • Sa filière d'études
  5. Cliquez sur "Contacter" pour envoyer une demande automatique
  6. Le mentor recevra une notification et pourra accepter ou refuser
Mes Matchings
  1. Allez dans "Correspondances" → "Mes matchings"
  2. Trois onglets sont disponibles :
    • Demandes reçues : Si vous êtes mentor, voyez qui vous contacte
    • Mes demandes envoyées : Voyez l'état de vos demandes
    • Matchings acceptés : Vos mentorats actifs
  3. Acceptez ou refusez les demandes reçues
  4. Un matching accepté crée automatiquement une conversation
Messagerie
  1. Accédez à "Messagerie" depuis le menu
  2. La liste de vos conversations s'affiche à gauche
  3. Cliquez sur une conversation pour l'ouvrir
  4. Tapez votre message et appuyez sur Entrée pour envoyer
  5. Les messages non lus sont marqués d'un badge
  6. Vous pouvez marquer tous les messages comme lus
Notifications
  1. Le badge dans la sidebar affiche le nombre total de notifications
  2. Les notifications incluent :
    • Messages non lus
    • Demandes de matching en attente
  3. Cliquez sur le badge pour voir le détail
Réinitialisation du Mot de Passe
  1. Sur la page de connexion, cliquez sur "Mot de passe oublié ?"
  2. Entrez votre adresse email
  3. Cliquez sur "Envoyer le lien"
  4. Vérifiez votre boîte mail (vérifiez le dossier Spam)
  5. Cliquez sur le lien de réinitialisation reçu
  6. Entrez votre nouveau mot de passe
  7. Confirmez et sauvegardez
Déconnexion
  1. Cliquez sur votre nom en haut à droite de l'écran
  2. Sélectionnez "Déconnexion"
  3. Vous serez redirigé vers la page de connexion
